🤖 all in one discord bot, written in python

# ❓ how to run
use the .env example:
```
TOKEN= # discord bot token
DB_PATH= # sqlite db path
```

# 💾 installation
```sh
$ git clone https://github.com/thrzl/megaton
$ cd megaton
$ uv sync
```
